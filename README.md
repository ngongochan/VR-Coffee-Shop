# VR Coffee Shop

An immersive VR coffee shop experience focused on atmosphere and experimentation, allowing players to interact with objects and walk around a cozy café space enhanced with spatial audio and lighting.

This project was created as the final project for **MDIA 2223 – Virtual Reality Design and Development I**.

## Features

* Smooth locomotion movement
* Real-time and baked lighting
* Spatial audio implementation for immersion
* Particle systems

## Technologies

* **3D Modeling:** Blender
* **Texturing:** Substance Painter
* **Language:** C#
* **Game Engine:** Unity
* **Framework:** VR Interaction Framework (VRIF)

## Prerequisites

* **Unity Hub**
* **Unity Editor:** `6000.0.39f1`

## Installation

1. Download the `.zip` file from the repository's `main` branch

2. Extract the `.zip` file

3. Open **Unity Hub**

4. Click `Add` → `Add project from disk`

5. Select the extracted project folder

Example: `.\Downloads\VR-Coffee-Shop-main\VR-Coffee-Shop-main`

6. Open the project folder through Unity Hub
