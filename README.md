# VR Coffee Shop

An immersive VR coffee shop experience focused on atmosphere and experimentation, allowing players to interact with objects and walk around a cozy café space enhanced with spatial audio and lighting.

This project was created as the final project for **MDIA 2223 – Virtual Reality Design and Development I**.

## Features

* Smooth locomotion movement
* Real-time and baked lighting
* Spatial audio implementation for immersion
* Particle systems

## Technologies

* **3D Modeling:** Blender
* **Texturing:** Substance Painter
* **Language:** C#
* **Game Engine:** Unity
* **Framework:** VR Interaction Framework (VRIF)

## Prerequisites

* **Unity Hub**
* **Unity Editor:** `6000.0.39f1`

## Installation

**1. Clone the repository**
```
$ git clone https://github.com/ngongochan/VR-Coffee-Shop.git
```

**2. Enter the project folder**
```
$ cd VR-Coffee-Shop
```

**3. Install Git LFS (only needed once per machine)**
```
$ git lfs install
```

**4. Pull LFS files**
```
$ git lfs pull
```

**5. Open Unity Hub**

* Click `Add`
* Select `Add project from disk`
* Choose the cloned project folder

Example path:
`.\Downloads\VR-Coffee-Shop`

**6. Open the project in Unity**

In Unity Editor, open your scene:
```
Assets/MyScene.unity
```
